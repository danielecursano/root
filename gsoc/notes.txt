For exercise 4, my initial approach was to include in the final model configuration only the attributes defined at the lowest layer level (the expected_attributes defined in hls4ml.model.layers). I chose this solution because hls4ml, when building a ModelGraph, uses an hls backend by default which adds additional parameters to the layers.

However, while working on Exercise 5, I realized that I needed to include some additional layer attributes in order to correctly build the corresponding ROperators in the SOFIE model. 

Regarding exercise 5, I implemented all the mentioned operators and tested them with different models.
All available tests are located in gsoc/test and you can run the tests using python -m test.(test_parser/test_hls2sofie)
I also wrote a test for function 4 using the provided onnx model. I followed hls4ml onnx conversion guide in order to parse the model correctly.

At the moment the rmodel generated supports only the float type, like in the SOFIE keras parser.

In the end, I refactored the makeOperators methods so that they can directly modify the rmodel when adding additional information about tensors or shapes used in the model. This design avoids using multiple if statements in the main function.
